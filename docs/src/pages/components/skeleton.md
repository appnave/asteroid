---
title: QasSkeleton
---

Um simples componente com fundo branco e bordas arredondadas para encapsular o seu conteúdo.Componente wrapper do "QSkeleton" que facilita a criação de skeletons com padrões pré-definidos para componentes do Asteroid.

<doc-api file="skeleton/QasSkeleton" name="QasSkeleton" />

:::info
##### Prop "type"
É possível passar todas props type do `QSkeleton` do quasar e passar custom types, sendo elas:
- QasBadge
- QasActionsMenu
- QasCheckbox
- QasBtn
- QasToggleVisibility
- QasTextTruncate
- QasStatus
:::
